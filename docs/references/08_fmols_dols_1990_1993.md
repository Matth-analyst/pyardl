# Spec 08 — Phillips & Hansen (1990), Stock & Watson (1993) : estimateurs efficaces du long terme (FMOLS, DOLS)

## Références
Phillips & Hansen (1990), *REStud*, 57(1), 99–125 (FMOLS) ;
Stock & Watson (1993), *Econometrica*, 61(4), 783–820 (DOLS).
Clés : `phillips1990fmols`, `stock1993dols` · Branche : **2**.
Module : `ardlpy.cointegration` · Priorité : v0.3 (estimateurs de
robustesse, très demandés dans les papiers appliqués en complément ARDL).

## 1. Rôle
L'OLS statique sur variables cointégrées (spec 06) est convergente mais
son inférence est invalide (biais de second ordre + endogénéité des
régresseurs + autocorrélation). FMOLS et DOLS corrigent et rendent
l'inférence asymptotiquement standard. Dans la pratique appliquée, ils
servent de vérification de robustesse des θ_j de l'ARDL — la bibliothèque
doit produire un tableau comparatif ARDL vs FMOLS vs DOLS vs CCR en une
ligne de code.

## 2. DOLS — algorithme (le plus simple, à faire en premier)
Modèle : y_t = det + θ'x_t + Σ_{i=-K}^{K} d_i' Δx_{t+i} + u_t
1. Construire leads et lags de Δx (helper `lead_lag_matrix(x, K_lead,
   K_lag)` — étend lag_matrix spec 02).
2. Choix de K : règle T^(1/3) par défaut + option IC (grille sur K,
   échantillon commun).
3. OLS ; l'inférence sur θ requiert une variance de long terme :
   se corrigés via HAC (Newey-West, bande d'Andrews ou de Newey-West
   automatique) sur u_t → t-stats asymptotiquement N(0,1).

## 3. FMOLS — algorithme
1. OLS statique → û_t ; Δx_t → v̂_t.
2. Estimer les matrices de covariance de long terme Ω et Λ (one-sided)
   du vecteur (û, v̂) par noyau (Bartlett par défaut, bande automatique) —
   implémenter `longrun_covariance_kernel(U, kernel, bandwidth)` dans
   `ardlpy.utils` (réutilisé ailleurs).
3. Correction d'endogénéité : y⁺_t = y_t − Ω_uv Ω_vv⁻¹ v̂_t.
4. Correction de biais : terme λ⁺ = Λ_vu − Λ_vv Ω_vv⁻¹ Ω_vu.
5. θ̂_FM = (Σ x̃ x̃')⁻¹ (Σ x̃ y⁺ − T λ⁺) (x̃ = x démeané selon det) ;
   V̂ basée sur Ω_u.v = Ω_uu − Ω_uv Ω_vv⁻¹ Ω_vu.
6. Option CCR (Park) : même infrastructure, transformation des données
   au lieu de la statistique — l'ajouter (les revues le demandent souvent).

## 4. API
```python
dols(y, X, det="const", k_leads=None, k_lags=None, ic=None)
fmols(y, X, det="const", kernel="bartlett", bandwidth="auto")
ccr(y, X, ...)
compare_longrun(ardl_results, y, X) -> DataFrame  # θ par méthode + se
```

## 5. Tests
1. DGP cointégré avec endogénéité contrôlée : biais OLS visible, corrigé
   par FMOLS/DOLS (biais MC < 10 % de celui de l'OLS, T=200, 1000 MC) ;
   couverture des IC à 95 % ∈ [92, 97] %.
2. Validation externe : concordance avec R `cointReg` (FMOLS/DOLS) à 1e-6
   sur données publiques ; DOLS recoupé avec une OLS-HAC manuelle.
3. Noyau LR : sur bruit blanc, Ω → variance vraie (consistance).
