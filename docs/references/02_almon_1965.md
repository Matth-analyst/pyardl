# Spec 02 — Almon (1965) : retards distribués polynomiaux (PDL)

## Référence

Priorité : v0.5 (module historique) — spec complète dès maintenant.

## 1. Le modèle

### 1.1 Modèle à retards distribués finis (FDL)

y_t = α + Σ_{i=0}^{q} β_i x_{t-i} + ε_t

Contrairement à Koyck (spec 01), le nombre de retards q est **fini** et la
forme des β_i n'est pas géométrique. Problème : pour q grand, estimer q+1
coefficients libres par OLS est très imprécis (multicolinéarité entre les
x_{t-i}).

### 1.2 La restriction polynomiale d'Almon

Les coefficients sont supposés suivre un polynôme de degré r en i :

β_i = γ₀ + γ₁·i + γ₂·i² + ... + γ_r·i^r,   i = 0, 1, ..., q,   avec r < q

On passe de q+1 paramètres à r+1 paramètres. Formes typiques : r=2
(bosse quadratique : effet qui monte puis retombe), r=3.

### 1.3 Écriture matricielle (le cœur de l'implémentation)

Soit β = (β₀,...,β_q)' et γ = (γ₀,...,γ_r)'. Alors :

β = H γ,   où H est la matrice (q+1)×(r+1) d'éléments H[i, j] = i^j
(convention 0⁰ = 1).

Le modèle devient : y_t = α + Σ_j γ_j z_{j,t} + ε_t, où les régresseurs
transformés (« variables d'Almon ») sont :

z_{j,t} = Σ_{i=0}^{q} i^j · x_{t-i},   j = 0, ..., r

→ Une simple OLS de y sur [1, z₀, ..., z_r].

## 2. Algorithme d'estimation (étapes complètes)

1. **Validation des entrées** (`ardlpy.utils.check_series`, cf. spec 01) ;
   vérifier r < q ≤ T/3 (garde-fou, warning sinon) et T − q − r − 2 > 0
   (degrés de liberté positifs).
2. **Construire la matrice des retards** X_lag de taille (T−q)×(q+1) :
   colonne i = x_{t-i}, t = q+1..T. Helper réutilisable
   `ardlpy.utils.lag_matrix(x, q)` (servira aussi au cœur ARDL).
3. **Construire H** ((q+1)×(r+1)) : H[i,j] = i**j.
   ⚠ Conditionnement : pour q grand, i^j explose. Implémenter en interne
   la **base normalisée** H[i,j] = (i/q)^j (ou base de Tchebychev en option
   `basis="chebyshev"`), transparente pour l'utilisateur : seule γ change
   de paramétrisation, β = Hγ reste identique. Documenter.
4. **Régresseurs transformés** : Z = X_lag @ H, de taille (T−q)×(r+1).
5. **OLS** : régresser y (aligné sur t = q+1..T) sur [1 | Z] →
   (α̂, γ̂), V̂(γ̂), σ̂² (via lstsq, cf. conventions spec 01).
6. **Retour aux β** : β̂ = H γ̂ ;  V̂(β̂) = H V̂(γ̂) H'.
   Les écarts-types individuels se(β̂_i) = sqrt(diag(V̂(β̂))).

---

## 3. Restrictions de bord (endpoint constraints)

Options classiques, à implémenter via paramètre `endpoint` :

- `"none"` (défaut) : aucune.
- `"head"` : β_{−1} = 0 (l'effet démarre à zéro avant i=0).
- `"tail"` : β_{q+1} = 0 (l'effet s'éteint après q).
- `"both"` : les deux.

**Implémentation** : chaque contrainte est linéaire en γ :
Σ_j (−1)^j γ_j = 0 pour head (i = −1) ; Σ_j (q+1)^j γ_j = 0 pour tail
(adapter à la base normalisée !). Méthode : construire la matrice de
contraintes Rγ = 0, puis reparamétrer γ = N δ où N = base du noyau de R
(via `scipy.linalg.null_space`), estimer δ par OLS sur Z@N, et remonter :
γ̂ = N δ̂, β̂ = H N δ̂, V̂(β̂) = (HN) V̂(δ̂) (HN)'.
Chaque contrainte consomme 1 degré de liberté — vérifier r+1 − #contraintes ≥ 1.

---

## 4. Choix de (q, r) — sélection assistée

Méthode `AlmonModel.select_order(y, x, max_q, max_r, ic="aic")` :

1. Grille sur q = r+1..max_q, r = 1..max_r.
2. ⚠ **Comparabilité** : pour comparer des q différents, estimer tous les
   modèles sur l'échantillon commun t = max_q+1..T (sinon les IC ne sont
   pas comparables). C'est un piège classique — le documenter et le tester.
3. Retourner le tableau complet des IC (AIC, BIC, HQ) + le couple optimal.

## 5. Tests d'hypothèses spécifiques

1. **Test de la restriction polynomiale** (validité d'Almon) :
   F = [(SSR_restreint − SSR_libre)/(q − r)] / [SSR_libre/(T − q − q − 2)]
   où le modèle libre est le FDL non contraint (OLS sur les q+1 retards).
   Sous H₀ (le polynôme est correct) : F ~ F(q−r, ddl_libre).
   Exposer comme `.polynomial_restriction_test()`. Si rejet → warning
   suggérant d'augmenter r ou de passer au FDL libre / à l'ARDL.
2. **Test des restrictions de bord** : même logique (F entre modèle avec
   et sans endpoint constraints).
3. **Significativité jointe des retards** : F sur H₀ : β₀=...=β_q=0,
   équivalent à γ = 0.

## 6. Quantités post-estimation

| Propriété | Formule | Se |
|---|---|---|
| `.lag_weights` | β̂_i, i=0..q | diag(V̂(β̂)) |
| `.impact_multiplier` | β̂₀ | direct |
| `.longrun_multiplier` | Σ_i β̂_i = ι'Hγ̂ | ι'H V̂(γ̂) H'ι (exact, linéaire) |
| `.interim_multiplier(h)` | Σ_{i=0}^{h} β̂_i | forme linéaire → se exact |
| `.mean_lag` | Σ i·β̂_i / Σ β̂_i | delta method (helper spec 01) |
| `.plot_lag_distribution()` | β̂_i ± 1.96·se avec la courbe polynomiale | — |

Noter : contrairement à Koyck, le multiplicateur de long terme est une
**forme linéaire** de γ → pas besoin de delta method, se exact.

## 7. Diagnostics et prévision

- Diagnostics : mêmes que spec 01 §4 (Ljung-Box, JB, BP) ; ici pas de y
  retardé → le **DW classique est valide** (l'inclure), pas de h de Durbin.
- Erreurs autocorrélées : option `cov_type="hac"` (Newey-West via
  statsmodels) — fréquent sur données trimestrielles.
- `.forecast(x_future, horizon)` : direct (pas de récursion, pas de y
  retardé) : ŷ_{T+h} = α̂ + Σ β̂_i x_{T+h−i} ; exige le sentier de x sur
  l'horizon + les q dernières valeurs observées.

## 9. Cas limites et erreurs

- r ≥ q → `ValueError` (« la restriction ne restreint rien »).
- q trop grand vs T → warning + suggestion de select_order.
- H mal conditionné (cond > 1e10) malgré la base normalisée → basculer
  Tchebychev automatiquement avec info.
- Contraintes de bord rendant le modèle vide (r+1 − #contraintes < 1)
  → `ValueError` explicite.
- x quasi constant → variance nulle des z_j → erreur claire.

## 10. Plan de tests

### 10.1 Unitaires (DGP simulés, seed fixe)

1. **Récupération exacte** : DGP avec β_i suivant un vrai polynôme (q=8,
   r=2), T=2000 → β̂ à ±0.02 ; V̂(β̂) cohérente avec la dispersion Monte
   Carlo (500 réplications, accord à 10 %).
2. **Équivalence** : avec r = q, AlmonModel ≡ FDL libre (coefficients
   identiques à 1e-10) — test d'invariance fondamental.
3. **Bases** : `basis="power"` vs `"chebyshev"` → mêmes β̂ à 1e-8.
4. **Endpoints** : DGP avec β_{q+1}=0 vrai → le test de bord ne rejette pas ;
   DGP violant la contrainte → rejet (puissance).
5. **Restriction fausse** : DGP à β_i non polynomiaux →
   polynomial_restriction_test rejette (fréquence de rejet ≈ puissance
   attendue).
6. **Échantillon commun dans select_order** : vérifier explicitement que
   tous les candidats sont estimés sur les mêmes observations.

### 10.2 Validation externe

- R **dLagM** (`polyDlm`) : mêmes données publiques → coefficients à 1e-6.
- EViews (PDL) : reproduire un exemple documenté de la littérature
  pédagogique avec endpoint constraints — concordance des β̂ et du F.
- Croiser `.to_fdl()` avec une OLS statsmodels sur lag_matrix : identique.
