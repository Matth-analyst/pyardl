# Spec 03 — Sargan (1964) : la formulation proto-ECM

## Référence

## 1. Pourquoi cet article dans la généalogie

C'est la première utilisation opérationnelle d'un mécanisme de correction
d'erreur en économétrie appliquée : une équation de salaires où la
croissance des salaires réagit à l'écart de *niveau* entre salaire réel et
productivité à la période précédente. L'idée structurante :

**une dynamique en différences + un terme de rappel en niveaux = un modèle
qui distingue court terme et long terme.**

Aucun estimateur nouveau à implémenter ; ce que cette spec définit, ce sont
les **transformations algébriques ARDL ↔ ECM** que toute la bibliothèque
utilisera (specs 04, 07, 08, 13+ en dépendent).

## 2. Le résultat algébrique central : reparamétrisation exacte

### 2.1 Cas ARDL(1,1) (pédagogique, à documenter dans la vignette)

y_t = α + φ y_{t-1} + β₀ x_t + β₁ x_{t-1} + ε_t

se réécrit **exactement** (aucune hypothèse supplémentaire) :

Δy_t = α + β₀ Δx_t − (1−φ)[y_{t-1} − θ x_{t-1}] + ε_t

avec θ = (β₀+β₁)/(1−φ) le coefficient de long terme et λ_EC = −(1−φ) < 0
la vitesse d'ajustement (fraction du déséquilibre résorbée par période).

### 2.2 Cas général ARDL(p, q₁, ..., q_k) → ECM (à implémenter)

Modèle : y_t = α + δ·t + Σ_{i=1}^{p} φ_i y_{t-i} + Σ_{j=1}^{k} Σ_{i=0}^{q_j} β_{j,i} x_{j,t-i} + ε_t

Forme ECM exacte :

Δy_t = α + δ·t + λ y_{t-1} + Σ_j γ_j x_{j,t-1}
       + Σ_{i=1}^{p-1} ψ_i Δy_{t-i} + Σ_j Σ_{i=0}^{q_j-1} ω_{j,i} Δx_{j,t-i} + ε_t

**Formules de passage (le contrat de l'implémentation) :**

- λ = −(1 − Σ_{i=1}^{p} φ_i)
- γ_j = Σ_{i=0}^{q_j} β_{j,i}
- ψ_i = −Σ_{m=i+1}^{p} φ_m,  i = 1..p−1
- ω_{j,i} = −Σ_{m=i+1}^{q_j} β_{j,m},  i = 0..q_j−1  (donc ω_{j,0} exclut β_{j,0}
  seulement via la somme ; vérifier : ω_{j,0} = −(β_{j,1}+...+β_{j,q_j}),
  et le coefficient de Δx_{j,t} contemporain est β_{j,0} + ω-ajustement —
  dériver et TESTER numériquement, cf. §6.1, c'est la source d'erreurs n°1)
- Coefficients de long terme : θ_j = −γ_j / λ = Σβ_{j,i} / (1 − Σφ_i)

### 2.3 Sens inverse ECM → ARDL

Inverser les relations ci-dessus (système triangulaire, résolution
séquentielle). Nécessaire pour : simulations (spec dynamac), bootstrap
(rééchantillonner sous la forme ARDL puis retester en ECM).

## 3. Ce qu'on implémente

**Fonctions de `ardlpy.core.transforms` :**

```python
def ardl_to_ecm(params: ARDLParams) -> ECMParams: ...
def ecm_to_ardl(params: ECMParams) -> ARDLParams: ...
def longrun_coefs(params: ARDLParams) -> pd.Series:      # θ_j
def longrun_covariance(params, V) -> np.ndarray:          # delta method (helper spec 01)
def speed_of_adjustment(params) -> float:                  # λ
def half_life(params) -> float:                            # ln(0.5)/ln(1+λ)
```

**Conteneurs** : dataclasses `ARDLParams` / `ECMParams` portant ordres,
coefficients, cas déterministe (préparer les 5 cas de PSS, spec 07 — ici
seulement `const`/`trend` booléens), et V̂.

**Détails d'implémentation :**
1. Représentation interne : polynômes de retard sous forme de vecteurs
   numpy ; les transformations §2.2 sont des sommes cumulées inversées
   (`np.cumsum` sur coefficients retournés) — pas de boucles Python.
2. `longrun_covariance` : gradient analytique de θ_j = Σβ/(1−Σφ)
   (∂θ/∂β_{j,i} = 1/(1−Σφ) ; ∂θ/∂φ_i = θ_j/(1−Σφ)) ; fallback gradient
   numérique du helper générique pour vérification en test.
3. `half_life` : valide seulement si −1 < λ < 0 (sinon NaN + warning
   « pas de convergence vers l'équilibre »).
4. Gestion des cas dégénérés dès maintenant : si |λ| < tol (pas de force
   de rappel) → θ non défini → NaN + warning pointant vers les tests de
   dégénérescence (specs 14-15). C'est ici que le concept entre dans la lib.

## 4. Leçon méthodologique de Sargan à encoder dans la doc

La vignette associée doit expliquer le débat « niveaux vs différences » :
modéliser en différences pures jette l'information de long terme ;
modéliser en niveaux sur séries tendancielles risque la régression fallacieuse ;
l'ECM réconcilie les deux. C'est l'argument qui justifie l'existence même
de la bibliothèque — le raconter avec l'équation de salaires de Sargan
comme illustration historique (salaires réels rappelés vers la productivité).

## 5. API d'exposition utilisateur

Sur tout objet résultat du cœur (specs 07+) :
- `.to_ecm()` / `.to_ardl()` : conversion de représentation (mêmes données,
  mêmes ε̂ — le vérifier).
- `.longrun` : Series des θ_j avec se.
- `.adjustment` : λ, se, half_life.

## 6. Plan de tests

### 6.1 Tests algébriques (les plus importants de la spec)

1. **Aller-retour** : ardl_to_ecm ∘ ecm_to_ardl = identité (1e-12), sur
   1000 jeux de paramètres aléatoires, ordres p, q_j ∈ {1..5}, k ∈ {1..4}.
2. **Équivalence des régressions** : sur données simulées, estimer par OLS
   (a) la forme ARDL et (b) la forme ECM → résidus identiques (1e-10),
   SSR identique, et coefficients liés exactement par §2.2. Ce test
   verrouille les formules de passage (la « source d'erreurs n°1 »).
3. **Long terme** : θ calculé par transformation = θ par simulation
   (réponse à un step de x, horizon 500) à 1e-6.
4. **Covariance delta** : gradient analytique = gradient numérique (1e-6).

### 6.2 Validation externe

- R `ARDL` (Natsiopoulos) : `uecm()` et `multipliers()` sur le jeu de
  données danois du package → θ_j et λ identiques à 1e-6.
- statsmodels `UECM.from_ardl` : concordance des reparamétrisations.
