# Spec 04 — Davidson, Hendry, Srba & Yeo (1978) : le DHSY, l'ECM opérationnel

## Référence
DHSY (1978), *The Economic Journal*, 88(352), 661–692. DOI: 10.2307/2231972.
Clé : `davidson1978dhsy` · Branche : **1. Racines** · Module : `ardlpy.core` +
vignette + jeu de données. Priorité : v0.1 (conventions) / v0.2 (dataset).

## 1. Apport pour la bibliothèque
Le DHSY transforme l'idée de Sargan (spec 03) en méthodologie complète de
spécification dynamique sur données trimestrielles (consommation UK). Trois
héritages concrets à encoder :

1. **Conventions de spécification** : variables en log-niveaux, ECM avec
   terme de rappel log(C/Y)_{t-s} (un ratio = restriction d'homogénéité
   θ = 1), différences saisonnières Δ₄ pour données trimestrielles.
2. **Stratégie de réduction** : partir d'un modèle général suramplement
   paramétré et tester des restrictions successives (préfigure GETS, cf.
   spec 05) en exigeant à chaque étape des résidus propres et la constance
   des paramètres (→ CUSUM, spec 26).
3. **Encompassing** : un bon modèle doit expliquer pourquoi les modèles
   rivaux (différences pures, niveaux purs) semblent marcher.

## 2. Ce qu'on implémente

### 2.1 Différences saisonnières et opérateurs
`ardlpy.utils.diff(x, d=1, D=0, s=4)` : opérateur (1−L)^d (1−L^s)^D,
alignement d'index propre. Nécessaire pour reproduire le DHSY et utile
partout.

### 2.2 Restrictions d'homogénéité sur le long terme
Sur tout ECM (spec 03) : méthode `.test_longrun_restriction(R, r)` —
test de Wald sur Rθ = r (delta method pour V̂(θ)), cas d'usage canonique
H₀ : θ_revenu = 1 (élasticité unitaire consommation/revenu). Étapes :
1. θ̂ et V̂(θ̂) via spec 03 ;
2. W = (Rθ̂−r)' [R V̂ R']⁻¹ (Rθ̂−r) ~ χ²(rang R) ;
3. option `impose=True` : ré-estimer l'ECM avec le ratio contraint
   (y − x) comme régresseur de niveau, comparer par F.

### 2.3 Variables déterministes saisonnières
Support des dummies saisonnières dans le cas déterministe des modèles
(extension des conteneurs de la spec 03 : `seasonal=True, s=4`).

### 2.4 Jeu de données d'exemple
`ardlpy.datasets.load_uk_consumption()` : consommation, revenu, prix UK
trimestriels (source publique ONS/reconstruction), pour la vignette
« l'ECM historique » et les tests de non-régression.

## 3. Tests
1. Wald d'homogénéité : sur DGP avec θ=1 vrai → taille ~5 % (1000 MC) ;
   θ=1.3 → puissance croissante en T.
2. `impose=True` : SSR contraint ≥ SSR libre, F cohérent avec le Wald.
3. diff : (d=1,D=1,s=4) sur série connue → valeurs vérifiées à la main.
4. Validation externe : reproduire qualitativement l'équation DHSY sur le
   dataset (signe et ordre de grandeur du coefficient de rappel).
