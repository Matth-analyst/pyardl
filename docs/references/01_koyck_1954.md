# Spec 01 — Koyck (1954) : modèle à retards distribués géométriques

## Référence

Clé BibTeX : `koyck1954distributed` · Branche : **1. Racines (distributed lags)**
Module cible : `pyardl.distributed_lags` · Classe : `KoyckModel`
Priorité : v0.5 (module historique) — mais spec complète dès maintenant.

---

## 1. Le modèle

### 1.1 Modèle structurel (retards distribués infinis)

y_t = α + Σ_{i=0}^{∞} β_i x_{t-i} + ε_t,  avec β_i = β₀ λ^i,  0 < λ < 1

Hypothèses : ε_t ~ iid(0, σ²), x_t faiblement exogène, |λ| < 1 (stabilité).

### 1.2 Modèle transformé (forme estimable)

En calculant y_t − λ y_{t-1}, la somme infinie se télescope :

y_t = α(1 − λ) + β₀ x_t + λ y_{t-1} + u_t,   u_t = ε_t − λ ε_{t-1}   (MA(1))

Paramétrisation de régression : y_t = c + b·x_t + ρ·y_{t-1} + u_t
Correspondance : λ̂ = ρ̂ ; β̂₀ = b̂ ; α̂ = ĉ / (1 − ρ̂).

---

## 2. Estimateurs à implémenter (3 méthodes)

### 2.1 Méthode `"ols"` — OLS naïf (avec avertissement)

**Étapes :**
1. Construire y_{t-1} (perd 1 observation) ; aligner y, x, y_{t-1} sur t = 2..T.
2. X = [1, x_t, y_{t-1}] ; OLS : θ̂ = (X'X)⁻¹X'y via `numpy.linalg.lstsq`
   (jamais l'inverse explicite).
3. Résidus û, σ̂² = û'û/(n − 3), V̂(θ̂) = σ̂²(X'X)⁻¹.
4. Récupérer (α̂, β̂₀, λ̂) par la correspondance §1.2.

**Comportement obligatoire :** émettre un `UserWarning` documenté :
l'OLS est biaisé et non convergent car Cov(y_{t-1}, u_t) = −λσ² ≠ 0
(u_t contient ε_{t-1} qui est dans y_{t-1}). Fournir quand même le résultat
(utile pédagogiquement et pour comparaison).

### 2.2 Méthode `"iv"` — Variables instrumentales (défaut, à la Liviatan)

Instrument pour y_{t-1} : x_{t-1} (corrélé à y_{t-1}, non corrélé à u_t
sous exogénéité de x).

**Étapes (2SLS) :**
1. Z = [1, x_t, x_{t-1}] (instruments), X = [1, x_t, y_{t-1}].
2. θ̂_IV = (Z'X)⁻¹ Z'y  (modèle juste-identifié → IV simple).
3. Variance : V̂ = σ̂² (Z'X)⁻¹ (Z'Z) (X'Z)⁻¹ avec σ̂² sur les résidus
   structurels û = y − Xθ̂_IV.
4. **Diagnostic d'instrument faible** : F de première étape (régression de
   y_{t-1} sur Z) ; avertir si F < 10.
5. Correspondance §1.2 pour (α̂, β̂₀, λ̂).

### 2.3 Méthode `"ml"` — Maximum de vraisemblance (gère le MA(1) des erreurs)

Le modèle transformé a des erreurs MA(1) avec coefficient −λ **identique**
au λ de la dynamique : contrainte croisée qu'exploite le ML.

**Étapes :**
1. Paramètres libres : ψ = (α, β₀, λ, σ²), avec λ ∈ (0, 1) via
   reparamétrisation logistique λ = 1/(1+e^{−ζ}) pour l'optimisation libre.
2. Log-vraisemblance conditionnelle : pour t = 2..T, construire récursivement
   ε̂_t = y_t − α(1−λ) − β₀x_t − λy_{t-1} + λε̂_{t-1}, avec ε̂_1 = 0.
   ℓ(ψ) = −(n/2)log(2πσ²) − Σ ε̂_t² / (2σ²).
3. Concentrer σ² : σ̂²(α,β₀,λ) = Σε̂_t²/n ; maximiser sur (α, β₀, ζ)
   via `scipy.optimize.minimize` (L-BFGS-B), point de départ = estimées IV.
4. Écarts-types : inverse de la hessienne numérique (via
   `statsmodels.tools.numdiff.approx_hess`) + delta method pour repasser
   de ζ à λ : se(λ̂) = se(ζ̂) · λ̂(1−λ̂).

## 3. Quantités dérivées (post-estimation)

Toutes avec écart-type par **méthode delta** : pour g(θ̂),
V̂(g) = ∇g' V̂(θ̂) ∇g. Implémenter un helper générique
`_delta_method(g, theta_hat, V_hat)` avec gradient numérique (réutilisable
dans toute la bibliothèque — le garder dans `pyardl.utils`).

| Propriété | Formule | Gradient (∂/∂β₀, ∂/∂λ) |
|---|---|---|
| `.impact_multiplier` | β₀ | (1, 0) |
| `.longrun_multiplier` | β₀/(1−λ) | (1/(1−λ), β₀/(1−λ)²) |
| `.mean_lag` | λ/(1−λ) | (0, 1/(1−λ)²) |
| `.median_lag` | ln(0.5)/ln(λ) | (0, −ln(0.5)/(λ ln²λ)) |
| `.interim_multiplier(h)` | β₀(1−λ^{h+1})/(1−λ) | dérivées analytiques |
| `.lag_weights(h)` | β_i = β₀λ^i, i=0..h | — |

IC à 95 % : g ± 1.96·se(g). Exposer aussi `conf_int(alpha)`.

## 4. Diagnostics (méthode `.diagnostics()`)

1. **h de Durbin** (le DW est invalide avec y retardé) :
   h = ρ̂₁ · sqrt(n / (1 − n·V̂(λ̂))) où ρ̂₁ = autocorrélation d'ordre 1
   des résidus. Sous H₀ : h ~ N(0,1). **Cas limite obligatoire** : si
   n·V̂(λ̂) ≥ 1, h est incalculable → basculer automatiquement sur le
   test alternatif de Durbin (régression de û_t sur û_{t-1} et X, test t
   sur û_{t-1}) et le signaler dans la sortie.
2. **Ljung-Box** sur les résidus (réutiliser `statsmodels.stats.diagnostic.acorr_ljungbox`).
3. **Jarque-Bera** (normalité) et **Breusch-Pagan** (hétéroscédasticité).
4. Pour `"ml"` : vérifier que les ε̂_t récursifs sont bien bruit blanc
   (c'est le test de la contrainte MA(1) croisée).

---

## 5. Prévision (méthode `.forecast(x_future, horizon)`)

Récursive sur le modèle transformé :
ŷ_{T+h} = α̂(1−λ̂) + β̂₀ x_{T+h} + λ̂ ŷ_{T+h−1}, initialisé à y_T.
Variance de prévision (erreurs MA(1)) : à h=1, σ̂²(1+λ̂²) ; accumuler
récursivement pour h>1 (documenter la formule dans la docstring).
Nécessite le sentier futur de x fourni par l'utilisateur — lever une
`ValueError` explicite sinon.

longueurs égales, pas de NaN internes (NaN de bord → trim avec warning),
n ≥ 15 sinon warning petit échantillon, variance non nulle, index temporel
pandas préservé si fourni.

## 7. Cas limites et erreurs à gérer

- λ̂ ∉ (0,1) en OLS/IV : ne pas tronquer ; avertir que le modèle géométrique
  est rejeté par les données (les multiplicateurs de LT n'ont alors pas de sens
  → renvoyer NaN avec warning).
- λ̂ → 1 : longrun_multiplier explose ; si λ̂ > 0.98, warning « mémoire
  quasi infinie, suspicion de racine unitaire, voir bounds test (spec 07+) ».
- Colinéarité x_t / x_{t-1} très forte (IV faible) : cf. F de 1re étape.
- Échec de convergence ML : renvoyer les estimées IV avec flag
  `converged=False` plutôt que lever une exception.

## 8. Plan de tests

### 8.1 Tests unitaires (données simulées, seed fixée)

1. **Consistance IV et ML** : DGP avec α=2, β₀=0.8, λ=0.6, T=5000 →
   estimées à ±0.02 des vraies valeurs. OLS avec ε autocorrélés → biais
   attendu documenté (le test vérifie que le biais EST là).
2. **Delta method** : comparer les se analytiques aux se bootstrap
   (1000 réplications) sur un DGP fixe — accord à 10 %.
3. **Cas limites** : λ vrai = 0.97 → warning émis ; série avec NaN de
   bord → trim correct ; n=10 → warning.
4. **Récursion ML** : sur DGP sans autocorrélation de ε, les ε̂_t récursifs
   passent Ljung-Box.

### 8.2 Validation externe

- Reproduire les sorties de `dLagM::koyckDlm` (R, estimation IV) sur un
  jeu de données public identique (ex. données de consommation du package) :
  coefficients à 1e-6, se à 1e-4 (méthodes de variance possiblement
  différentes → documenter tout écart).
- Croiser `.to_ardl()` avec l'ARDL(1,0) de `statsmodels` : coefficients
  identiques par construction.
