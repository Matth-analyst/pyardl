# Spec 07 — Johansen (1988, 1991) : cointégration en système VAR

## Références
Johansen (1988), *JEDC*, 12, 231–254 ; Johansen (1991), *Econometrica*,
59(6), 1551–1580. Clés : `johansen1988statistical`, `johansen1991estimation`.
Branche : **2** · Module : `pyardl.cointegration` · Priorité : v0.3
(wrapper) — pas de réimplémentation complète.

## 1. Rôle dans la bibliothèque
Approche système : VECM Δy_t = Πy_{t-1} + Σ Γ_i Δy_{t-i} + det + ε_t,
rang(Π) = nombre de relations de cointégration, testé par les statistiques
de trace et de valeur propre maximale (valeurs propres du problème
généralisé issu des régressions auxiliaires).

Pourquoi on en a besoin (et seulement pour ça) :
1. **bootCT/Bertelli (spec 16)** exécute un test de Johansen sur les
   variables indépendantes du modèle ARDL — vérifier qu'il n'y a pas de
   cointégration *entre les x* (hypothèse du cadre bounds à k relations).
2. Comparaison pédagogique bounds vs système dans les vignettes.
3. Génération de données : le simulateur VECM (spec 16 §sim) doit produire
   des données dont le rang est contrôlé — le test de Johansen sert de
   vérification.

## 2. Implémentation : wrapper + compléments

**Décision d'architecture** : ne pas réimplémenter — wrapper mince autour de
`statsmodels.tsa.vector_ar.vecm.coint_johansen` (mature, validé), avec :

1. API harmonisée pyardl : `johansen(Y, det_order, k_ar_diff)` →
   `JohansenResults` (trace_stat, maxeig_stat, cv aux 3 seuils, rang
   séquentiel retenu à 5 %, valeurs propres, vecteurs β normalisés).
2. **Procédure séquentielle automatisée** : tester r=0, 1, ... jusqu'au
   premier non-rejet → `.selected_rank` (statsmodels donne les stats, pas
   la décision).
3. Helper dédié au cadre bounds : `check_no_cointegration_among_x(X, ...)`
   → warning structuré si rang > 0 parmi les x (utilisé par specs 10, 15,
   16 comme diagnostic préalable).

## 3. Tests
1. DGP VECM de rang 1 (3 variables) → selected_rank = 1 dans ≥ 90 % des
   1000 MC (T=200) ; rang 0 → taille ~5 %.
2. Concordance avec R `urca::ca.jo` sur les données danoises (mêmes stats
   de trace à 1e-4 — attention aux conventions de déterministes, les
   documenter dans un tableau de correspondance pyardl/statsmodels/urca).
3. check_no_cointegration_among_x : détecte une paire cointégrée injectée.
